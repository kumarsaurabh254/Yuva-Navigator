# GitHub source/adaptation notes

The user supplied the GitHub fitness-website topic page:
https://github.com/topics/fitness-website?l=html

For the adaptation, the vanilla HTML/CSS/JS repository selected from that topic was:
Vroomfrondal/Fitness-Website
https://github.com/Vroomfrondal/Fitness-Website

The repository describes itself as a responsive gym website built with vanilla HTML, CSS and JavaScript. Its source structure includes multiple HTML pages, a shared CSS file and JavaScript, including a nutrition page.

This SportFit Pathfinder build does NOT retain the original Forward Fitness branding, contact information, gym claims or navigation. Useful structural ideas such as responsive multi-page HTML/CSS/JS organization, shared navigation, responsive grid/card layouts and a dedicated nutrition page were adapted to the user's SIH requirements.

Original source should be reviewed for its applicable license/permissions before public redistribution. This ZIP is an adaptation for the user's prototype.
